# 📝 To-Do List

Uma aplicação web simples, intuitiva e responsiva para gerenciamento e organização de tarefas diárias.

## 🚀 Funcionalidades

* **Adicionar Tarefas:** Crie novas tarefas de forma rápida e prática.

* **Concluir Tarefas:** Marque itens como concluídos para acompanhar seu progresso.

* **Remover Tarefas:** Exclua tarefas concluídas ou desnecessárias.

* **Persistência de Dados:** Armazenamento das tarefas no navegador via `LocalStorage`.

* **Interface Responsiva:** Layout adaptável para dispositivos móveis e desktop com suporte a planos de fundo personalizados.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.

* **CSS3:** Estilização, layout responsivo e elementos visuais.

* **JavaScript (ES6+):** Manipulação do DOM e lógica da aplicação.

## 🔧 Como Executar o Projeto

1. **Clonar o Repositório:**

   ```
   git clone https://github.com/gitJoaoVLM/To-Do-List
   
   ```

2. **Acessar o Diretório:**

   ```
   cd To-Do-List
   
   ```

3. **Abrir a Aplicação:**

   * Abra o arquivo `index.html` em qualquer navegador web.

   * Caso utilize o VS Code, você pode usar a extensão **Live Server** para rodar localmente.
